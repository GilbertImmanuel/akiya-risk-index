# Data Licences and Attribution

This repository contains code (MIT) and data derived from Japanese government
statistics. The data are **not** covered by the MIT licence; they retain their
source terms.

## Core sources

| Source | Terms | Attribution |
|---|---|---|
| e-Stat / Statistics Bureau (Housing and Land Survey, Census) | CC BY 4.0-compatible; commercial use allowed | “Source: Statistics Bureau of Japan, [survey name], processed by the author.” |
| MLIT Real Estate Information Library | Free use with attribution; API key required | “Source: MLIT Real Estate Information Library.” |
| MLIT / 国土数値情報 | Free; commercial use permitted | “Source: MLIT National Land Numerical Information.” |
| GSI / 地理院タイル | Free; attribution required | “Source: Geospatial Information Authority of Japan.” |
| IPSS | Free; attribution required | “Source: National Institute of Population and Social Security Research.” |
| MLIT policy documents | Government standard terms | “Source: MLIT.” |
| Akiya-bank aggregates | Official aggregate PDFs / participation lists | “Source: MLIT / LIFULL / AtHome.” |
| OpenStreetMap (optional) | ODbL 1.0; share-alike | “© OpenStreetMap contributors.” |

## Notes

- The processed municipal panel is a **derived work**. Cite the original surveys
  and note that the panel was built by this project.
- Do not redistribute API keys or scrape akiya-bank listing pages.
- Some sources are updated annually or every five years; check the access date
  in the data dictionary before reuse.

See `research/data-sources.md` for the full inventory and caveats.
