# Site Data

Precomputed JSON and GeoJSON for the browser. Generated by `src/07_export_map.py`.

- `municipalities.geojson` — simplified municipal boundaries and class fields.
- `panel.json` — one record per municipal unit with the six indicator values.
- `meta.json` — metric definitions, fixed breaks, colors, and coverage notes.

Do not hand-edit these files; regenerate them.
